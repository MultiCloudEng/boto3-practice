Managing EC2 using boto3
Programmatically controlled EC2 using method try/except to understand deeply UnauthorizedOperation when principle leastprivilege is not enough granted permissions to fully control EC2 and its behavior.
Scripts

list-instances.py — show EC2 instances
start-instances.py — starts EC2 instances
stop-instances.py — stops EC2 instances
Requirements
pip install boto3
python 3.14.7
aws configure for aws credentials
Usage
python3 list-instances.py
